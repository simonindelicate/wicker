# Wicker tarot: Krea 2 prompts

Every prompt below is complete in itself, so it can be pasted straight in. They share a common style passage, so the cards read as one deck: an old hand-printed tarot crossed with a 1970s English folk-horror film still.

**Before you start:**

- **Aspect ratio.** Generate at a tall tarot ratio, about 7:12 (for example 1050 × 1800).
- **Card text.** The card's numeral and title are written into each prompt. Image models often misspell words, so if a card comes back garbled, delete the sentence starting "Across the bottom border…" and add the text yourself afterwards. The rest of the prompt doesn't depend on it.
- **Tribe colours.** These match the game: Ochre `#d39b3c`, Blood `#b8392f`, Forest `#33c4a0`, Ash `#d8d2c5`. Each card names one, so you can swap it to make a set for another tribe.

**If the model struggles:** the style passage is the part that holds the deck together, so keep it word for word and vary only the subject. If the results come out too clean or modern, add "rough, imperfect, hand-carved, nineteenth-century chapbook print". If they come out too dark, add "daylight, readable, clear figure".
