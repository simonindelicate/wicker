# Wicker

A folk-horror god game in a single HTML file. Open `index.html` in a browser to play; it loads three.js and two Google fonts from CDNs and needs nothing else.

- `index.html`: the current build, with the twenty-level campaign.
- `waypoints/`: earlier builds kept as fallbacks.
  - `wicker-2026-10-08-rook-tree.html`: before the maypole, May Queen and sacrifice spectacles.
  - `wicker-2026-10-09-pre-campaign.html`: before the campaign.

Tuning lives near the top of the script: search for `WICKER: TUNING`, `CAMPAIGN` and `MODELS`.
