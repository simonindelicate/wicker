# Wicker

A folk-horror god game in a single HTML file. Open `index.html` in a browser to play; it loads three.js and two Google fonts from CDNs and needs nothing else.

- `index.html`: the current build, with the twenty-level campaign and Seasons of the Witch.

Tuning lives near the top of the script: search for `WICKER: TUNING`, `CAMPAIGN` and `MODELS`.
